## Design law

Different room. Same signal.

Season Zero should behave as a living broadcast/editorial world. Real Lauren and real proof remain the human center. Stardust is cinematography and material behavior around the media, not a UI theme and not a collection of decorative AI objects.

The chapter architecture remains:
Hero → Person → Explain → Create → Television → Host → Activate → Watch → Trust → Casting Imagination → Book.

Each chapter must have a distinct camera distance, visual physics and job while sharing the same pearl / icy-silver / optical material language.

## Review-build media rule

Review-candidate, private-review and pending-public-use assets may be used on this branch for internal composition review according to the Portfolio Max approval records. They are not automatically eligible for public release. Public-use clearance remains a separate release gate.

## Build gate
